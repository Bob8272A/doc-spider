# 🕷️ Doc Spider

A private, in-browser PDF summarizer. Drop in a document and it:

- gives you key points with an AI model that runs **entirely on your device**
- highlights dollar amounts, percentages, dates and links
- sends a spider crawling to the important numbers

No uploads, no accounts. Your documents never leave your browser.

**Try it:** https://bob8272a.github.io/doc-spider/

## Install
Open the link in Chrome or Edge and click **Install app**.

## Notes
- The AI summary needs a browser with WebGPU (recent Chrome or Edge). The first run downloads a model of about 1 GB, which is cached afterward.
- Scanned PDFs without selectable text aren't supported yet.
- Settings (⚙) has themes, accent colors, spider modes and speed, and model choice.
